HERALD V3 UPDATE - HOW TO APPLY

1. Close the START_HERALD.bat server window.
2. Extract this ZIP.
3. Move the entire HERALD_UPDATE_V3 folder inside your existing Herald project folder—the folder that contains SETUP_XAMPP.bat, START_HERALD.bat, backend, and frontend.
4. Open HERALD_UPDATE_V3 and double-click APPLY_UPDATE.bat.
5. Confirm the displayed project path and continue.
6. Start Herald again with START_HERALD.bat.
7. Sign in as Admin or Logistics and open Branches from the Operations menu.

The updater does not delete or reset your database. It does not overwrite backend/.env.
A small backup of the replaced production branch files is saved in _before_v3_update.
